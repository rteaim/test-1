# MAPO CAMPUS PLAYGROUND

마포고등학교 × 유석초등학교를 모티브로 한 비공식 브라우저 3D 샌드박스 게임 프로토타입입니다.

## 포함 기능
- Three.js 기반 3D 캠퍼스 및 카메라 조작
- 건물 선택, 가상 충격파·폭발·지진·중력장
- 영화적 핵폭발 연출(섬광·버섯구름·확산 충격파)
- 벙커버스터 연출(가상 수직 광선·지면 충격·파편 효과)
- 파편 애니메이션, 실행 취소, 전체 복구
- 모바일·태블릿·PC 브라우저 지원

핵폭발 및 벙커버스터는 게임 내 시각 효과일 뿐이며, 실제 무기 성능·제원·운용·제작 방법을 모델링하지 않습니다.

## GitHub Pages 배포
1. GitHub에서 새 **Public** 저장소를 만듭니다.
2. 압축을 풀고 `index.html`과 `README.md`를 저장소 최상위(root)에 업로드합니다. `index.html`이 반드시 최상위에 있어야 합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 선택하고 **Save**를 누릅니다.
6. 잠시 후 `https://깃허브아이디.github.io/저장소이름/` 주소가 생성됩니다. 이 주소를 공유하면 누구나 브라우저에서 접속할 수 있습니다.

## 참고
- Three.js 모듈을 jsDelivr CDN에서 가져오므로 첫 실행과 플레이에 인터넷 연결이 필요합니다.
- 현재는 각 이용자가 자기 브라우저에서 독립적으로 플레이합니다. 실시간 공동 파괴 상태·계정·공용 랭킹에는 별도 백엔드가 필요합니다.
- 캠퍼스 배치는 제공된 참고 이미지 기반의 개략적인 게임용 모델이며 실제 설계도나 측량 자료가 아닙니다.
- 학교와 공식 제휴·후원 관계가 없는 비공식 팬 프로젝트입니다.
